# SWAG OWNERS — Антифрод «без прослушки»

> Скоринг телефонных вызовов по метаданным «конверта» звонка.
> Без записи, без расшифровки, без одного слова из разговора.
> Только то, что оператор и так видит в сигнализации.

## Задача

Маркировка корпоративных звонков признана неэффективной — она просто подтягивает запись из базы и не подтверждает, кто на самом деле звонит. Регуляторный слой есть, поведенческого — нет.

Задание: отличить мошенника от обычного человека только по метаданным вызова — там, где содержимого разговора нет.

### Из чего берём признаки

По вызову:

- длительность
- время суток
- тип соединения
- страна и оператор источника
- отбой на первой секунде

По номеру за окно времени:

- вызовов в час
- уникальных собеседников
- охват регионов
- доля коротких вызовов
- доля неотвеченных

По графу связей:

- сколько номеров приходится на одного абонента
- есть ли «веер» — группа номеров, обзванивающая непересекающиеся списки по одному шаблону

Обязательное требование — объяснимость

Оператору бесполезен ответ «0,87». Нужны факторы с их вкладом, иначе решение нельзя ни отладить, ни защитить перед регулятором.

### Как выглядит результат

```
Вызов +7 495 *--12 → +7 916 *--83
14 октября 11:42 · длительность 6 сек · вход из-за рубежа
→ скоринг + разбор по факторам
```

Последняя строка — не случайность: автоблокировка по скорингу — отдельное решение с отдельной ценой ошибки.

### Как оцениваем

На закрытом наборе, с явным акцентом на долю ложных срабатываний. В ТЗ ставится прямой вопрос: «Что произойдёт, если ваша система заблокирует вызов скорой помощи?» Команды, которые на него ответят — видно сразу.
