Файлы `CDR_*.cdr` - записи коммутатора за период **2026-10-01 - 2026-10-05** (471 файлов, 2353333 записей). В потоке обычных звонков спрятаны схемы массовых прозвонов и мошенничества.

## Формат записи

Текстовый файл, поля через `;`, без заголовка:

| # | Поле | Пример |
|---|------|--------|
| 1 | Тип: 01 - входящий, 02 - исходящий, 03 - переадресация | `02` |
| 2 | IMSI абонента A (у городских и внешних номеров пусто) | `250021234567890` |
| 3 | Номер A: код оператора (3 цифры) + номер (7 цифр) | `8991234567` |
| 4 | Номер B | `0261234567` |
| 5 | Начало вызова `yyyymmddhh24miss` | `20260928083015` |
| 6 | Длительность, сек | `54` |
| 7 | Номер C - куда B переадресовал вызов (если тип 03) | `2101234567` |

Коды: городские 842, 499, 892; Альфа 025, 026, 027; Барбетта 899, 810, 834; Bell-ka 210, 214, 200.

> **Внимание:** коды Альфы начинаются с нуля (`0261234567`). Читайте номера как **строки** (`dtype=str` в pandas, текстовый формат столбца в Excel), иначе нули пропадут.

## Что нужно найти

В данных спрятаны схемы массовых прозвонов и мошенничества. Найдите номера, которые к ним относятся. Типы схем неизвестны; тип в ответе указывать необязательно.

> **Осторожно:** в данных есть легальные массовые источники (колл-центры, банковские оповещения и т.п.). Они похожи на фрод, но фродом не являются - за них штраф.

> В части строк встречаются ошибки формата (лишние поля, коды страны, неверные даты и т.п.). Решите, как их обрабатывать.

Текстовый файл, **один номер на строку**, 10 цифр. Тип схемы можно указать через `;`:

```

0261353431
```
